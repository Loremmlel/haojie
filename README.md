# 浩劫 · 双人对战回合制棋盘游戏

9 列 × 13 行的 117 格战场上，蓝红双方围绕 300 血的基地展开攻防——
从 26 种棋子库中随机召唤、部署、行动、施法，率先摧毁对方基地者获胜。

## 快速开始

```bash
node build.js        # 构建单文件成品 -> dist/haojie.html
node test/smoke.js   # 运行逻辑层冒烟测试（31 项断言 + 随机整局模拟）
```

构建产物 `dist/haojie.html` 是**零依赖的单个 HTML 文件**，双击即可在浏览器离线游玩。
本地双人同屏对战：两位玩家轮流操作鼠标即可。

## 项目结构

```
haojie/
├─ build.js            # 零依赖构建脚本：内联 CSS/JS 进模板
├─ package.json
├─ src/
│  ├─ template.html    # 页面骨架（占位符 /*__STYLE__*/ 与 //__SCRIPTS__）
│  ├─ css/style.css    # 视觉与动画体系
│  └─ js/
│     ├─ rng.js        # 可序列化种子随机（悔棋确定性回放的基石）
│     ├─ data.js       # 26 棋子定义 + 图鉴文案
│     ├─ state.js      # 游戏状态 / 快照悔棋栈 / 事件流
│     ├─ rules.js      # 曼哈顿几何 / 路径穿透 / 部署与移动合法性
│     ├─ engine.js     # 统一伤害管线（金身→厚脸皮→策反→守护→遗言→反弹）
│     ├─ abilities.js  # 主动技能注册表 & 死亡遗言
│     ├─ spells.js     # 五张法术的目标解析与结算
│     ├─ game.js       # 回合流程编排 + 对外 API
│     ├─ fx.js         # 特效引擎（弹道/斩击/飘字/震屏/横幅）
│     ├─ ui.js         # 棋盘双层渲染（格子全量重建 + 棋子 DOM diff）
│     ├─ input.js      # 交互状态机（busy 锁 + 异步目标选择）
│     ├─ codex.js      # 图鉴 & 规则说明
│     └─ main.js       # 入口装配
└─ test/smoke.js       # Node 直接运行的逻辑层测试
```

## 设计要点

- **逻辑与表现完全分离**：`rng…game` 八个文件不触碰 DOM，可在 Node 里直接驱动整局；
  表现层通过 `ENV.choose`（异步目标选择）注入交互、消费事件队列播放动画。
- **悔棋 = 快照栈**：每次玩家操作前压入完整状态快照（含随机数种子），
  撤销后随机序列完全一致；测试中对「操作 → 悔棋」做了逐字节还原校验。
- **穿透攻击**：对每个候选目标做多源 BFS，把其他敌方棋子视为墙体，
  存在 ≤ 射程的无阻路径才可攻击——前排肉盾真的能挡住后排输出。

## 快捷键

| 键 | 功能 |
|----|------|
| `E` | 结束回合 |
| `U` | 悔棋 |
| `Esc` / 右键 | 取消选择 |
